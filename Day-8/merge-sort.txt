Merge sort, you pass in an array to the merge sort function.
Divides the array into two sub arrays.
THIS FUNCTION IS RECURSIVE
So it will call itself again to keep making these subarrays until the arrays are holding just one element.
When the arrays hold one value you then merge the arrays in proper sort order.

4,1,3,6,2,5,7,8

(4,1,3,6) (2,5,7,8)

(4,1) (3,6) (2,5) (7,8)

(4) (1) MERGES INTO (1,4) --\
                            ------ Now merge these two into (1,3,4,6)
(3) (6) MERGES INTO (3,6) --/

(2) (5) MERGES INTO (2,5) --\
                            ------- Now merge these two into (2,5,7,8)
(7) (8) MERGES INTO (7,8) --/

FINAL MERGE: (1,2,3,4,5,6,7,8)


Runtime complexity of O(n log n), quasilinear time.

So in a large data set it is noticeably better than quadratic algorithms (insertion sort, seleciton sort , bubble sort).
A drawback however being more memory used due to the amount of sub arrays needed.
